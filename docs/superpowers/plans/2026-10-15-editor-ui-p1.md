## Ground grid continuity follow-up (2026-10-18)
- Root cause: the old overlay quantized spacing with `10^floor(log10(abs(cameraY)*.4))` and scaled its finite rectangle with that spacing. The initial camera height 2.5 sits exactly on a decade boundary, so small vertical motion replaced the grid with a rectangle ten times larger/smaller. Snapped camera-relative edges also shifted during translation.
- Replaced the rectangle with world-origin-aligned grid levels on Y=0. Density fades continuously using the projected perpendicular spacing of each line (including perspective foreshortening); distance fades hide the moving extent. World-anchored segmentation and whole-line frustum clipping avoid visible recentering and unnecessary offscreen work. Scene content and object transforms are unchanged.
- RED: real ImGui overlay rasterization changed by .058 mean opacity for .0002 vertical movement across height 2.5 (`Saved/grid-red.log`). An intermediate version exposed a bright horizon band (peak row opacity .9655) and excessive CPU work; an additional test reproduced it (`Saved/grid-horizon-red.log`). Both review findings were fixed before acceptance.
- Final raster checks isolate gray grid geometry, use geometric AA, assert visible coverage and bounded geometry, and cover old height boundaries, translation, near-ground horizontal views, top view and distant subpixel accumulation. Final mean deltas .000328 / .000051; horizon peak .130668. Eight new checks bring editor interaction coverage to 280 passing checks.
- Final Debug editor and both editor test targets build PASS (`Saved/grid-final-build.log`, `Saved/grid-final-tests-build.log`). Focused CTest: 3/3 PASS, 4.99 seconds (`Saved/grid-final-ctest.log`), including DPI and asset rename regressions.
- Actual Windows UI inspected in the user's existing test project: initial view, ViewCube drag orbit, enlarged viewport and layout restore. The horizon band is absent; Scene/UI time was approximately 2.4–3.2 ms in the normal docked view after optimization. A brief injected Q key produced no observable movement, so vertical boundary verification relies on the real-overlay regression tests.
- Independent re-review approved the final implementation. Existing project reopened with restored dock layout; usage guide updated. `git diff --check`: PASS. All existing uncommitted UI work preserved.
