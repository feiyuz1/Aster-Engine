## 0.25：内容制作与基础运行闭环

对应提交：`0b8ae87`、`b081777`、`9f0be94`。

### 已完成

- 渲染：Cubemap Irradiance/GGX Prefilter/BRDF LUT 离线烘焙、三段 CSM、透明阴影、逆转置法线矩阵、GPU 实例化、保守遮挡、Bloom/SSAO/TAA/FXAA/ACES 和各向异性过滤。
- Shader/材质：父材质和显式覆盖、Shader 参数反射、Material Graph、ORM/RMA Packed Texture、Shader 源码编辑和真实驱动错误定位。
- 资产：DDS/KTX2 BC1–BC7 读取、Texture/Material/Mesh 缩略图、丢失依赖修复、移动/重命名引用更新、`TINYCHUNK 1` 分块流式读取。
- 物理：Convex Hull Support Map/GJK、Triangle Mesh 三角形查询、统一 Shape Sweep、角色 Slide/Step/Slope、摩擦与角速度、扩展 Joint、可选 Jolt 构建入口。
- UI/文字：UTF-8、轻量 BiDi/连字/断行/富文本、动态 Glyph Atlas、InputField/List/Dropdown/ProgressBar。
- 编辑器：框选、多实体 Gizmo、World/Local、Pivot、渲染开关、Shader/Material Graph、资产预览维护、反射 Inspector Undo。

### 验证与边界

- 全目标构建、核心 CTest、真实 FBX/glTF 矩阵和 SDL2/OpenGL Demo 通过。
- 当时的遮挡和 TAA 后续已在 0.27 升级为 GPU HZB 和 Motion Vector TAA。
- Runtime 只消费已有 BC 数据，不内置质量敏感的 BC6H/BC7 编码器。
- 内建物理适合轻量场景；大型复杂刚体堆叠仍应完成 Jolt 项目级认证。

## 0.26：角色表现、扩展、AI 与联网基础

### 已完成

- 动画：同名/显式骨骼重定向、Two Bone IK、Root Motion 曲线、2D Blend Space、逐骨骼 Override/Additive 分层混合和骨架调试快照。
- VFX：`.vfx` 资产、CPU Flipbook 实例批次、无逐帧 CPU 粒子的 GPU 连续弹道路径及可视化编辑器。
- 音频/输入：stb_vorbis OGG 小块流式解码、44.1 kHz Mixer、跨手柄 Glyph 和 SDL 手柄震动回调。
- 插件：稳定 C ABI v1、动态/静态插件、版本/结构大小协商、Startup 回滚、逆序 Shutdown、Tick、日志和对齐内存桥接。
- 导航/AI：多边形 NavMesh、动态障碍、Crowd、EQS、Behavior Tree Graph 编辑与循环/引用校验。
- 联网：IPv4 UDP、Sequence/Ack/32 位窗口可靠通道、RPC 白名单与限流、Ownership、客户端预测纠错。

### 验证与边界

- Runtime、Editor、Game、Importer、工具和测试全目标构建通过；核心测试与真实导入矩阵继续通过。
- 重定向不是完整 IK Rig/Retarget Pose，IK 不是 Full Body IK。
- GPU VFX 尚不包含 Burst、碰撞、排序、Ribbon 或事件回读。
- 导航不是完整 Recast/Detour 烘焙；联网不包含大厅、NAT、认证加密、分片和反作弊服务。

## 0.27：现代渲染架构

### Render Graph 与帧资源

`RenderGraph` 使用逻辑 Texture/Buffer Handle，Pass 显式声明 Read/Write；编译阶段建立 RAW/WAR/WAW 依赖、稳定拓扑排序、未写先读/无效 Handle/环检测，并依据描述兼容性和非重叠生命周期计算瞬态 Alias Slot。

当前九个主 Pass：

1. Shadow Cascade 0
2. Shadow Cascade 1
3. Shadow Cascade 2
4. Forward+ Scene
5. GPU HZB
6. GTAO
7. Bloom Pyramid
8. Motion Vector TAA
9. Tone Map

### 已完成

- Forward+/Clustered：16×9 Tile、24 个对数深度 Slice、最多 64 Light，通过 Texture Buffer 向 Shader 提交 Cluster 表。
- Motion Vector TAA：HDR+Motion MRT、上一帧 ViewProjection/Model、History Ping-Pong、3×3 邻域约束和速度自适应权重。
- 独立后处理：保守最大深度 HZB、半分辨率八方向 GTAO、五级 Bloom 金字塔、曝光/ACES/Gamma 与可选 FXAA。
- GPU Driven：Compute 使用上一帧 HZB 压缩可见实例并更新 `DrawElementsIndirectCommand.instanceCount`，随后 `glDrawElementsIndirect`；失败时保留 CPU 回退。
- 编辑器/诊断：Scene View 暴露 Bloom/GTAO/TAA/FXAA/曝光，Stats 记录 Render Graph、Cluster、HZB 和 GPU Driven 状态。

### 验证与边界

- 核心测试覆盖 Render Graph 编译/执行/错误/别名、Cluster 分配和九 Pass 帧图；Demo、Editor 与真实模型矩阵通过。
- Render Graph 尚未抽象真实 GPU Barrier、Queue、Descriptor 或跨 API Physical Resource Pool。
- Cluster 表仍由 CPU 构建；实例批次尚未合并为全场景 Multi Draw Indirect。
- GTAO 没有完整时空降噪，TAA 没有 Reactive Mask、透明速度、曝光补偿或 TAAU。
- 当前只有 OpenGL 4.3；Vulkan/D3D12/Metal、异步 Compute、Bindless、Mesh Shader 与 Virtual Geometry 属于后续升级。
