## 实施决定

1. 使用独立工作树并保存工作区基线，保护原目录的未提交改动。代价：集成时必须相对此基线处理，不能重置原目录。
2. 中文路径测试暴露 Config 的窄字符转换问题，扩展 UTF-8 文件系统边界。代价：提供本地代码页编码路径的调用方须改用 UTF-8，与资产序列化一致。
3. 共享 Shader 源码嵌入提前至任务 4，保证旧内置 Shader 回归持续可用。代价：任务 8 验证并扩展同一机制，不再增加第二套嵌入流程。

## 验证中发现并修复的问题

- GLSL 的保留字 `packed` 被用于生成局部变量，真实 GPU 编译发现后改名。
- 扩展打包测试硬编码 Release 路径却要求 Debug 元数据，改为 CMake 当前配置的实际游戏目标路径。
- 旧资产使用项目相对贴图路径；搬移时补足兼容匹配，防止破坏引用。引用写入失败时恢复资产、元数据和已改写文件。
- 旧 alpha 小于 1 的隐式透明状态在适配时丢失，改为保留有效透明状态。
- 中文物理目录的原子保存改用原生路径追加后缀；并发保存使用独立临时名并串行发布，防止 Windows ReplaceFile 争用目标。
- 一次全量与专项测试并行读写相同回归目录，造成测试冲突；最终验收串行运行。

首版继续保留现有 Alpha 混合与随机透明阴影近似。精确前帧骨骼速度、材质函数、静态开关、多 UV、顶点位移、清漆、折射，以及 GI / Lightmap / 反射探针不属于本期。
