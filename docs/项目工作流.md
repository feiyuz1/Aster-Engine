# 新建项目与编写游戏代码

本文说明 TinyEngine 当前的基础 C++ 项目工作流。需要 Windows、Visual Studio 2022、CMake 3.20+，并先按[构建指南](构建指南.md)编译编辑器。

1. 不带项目参数启动 `tinyengine_editor.exe`，进入项目启动页。
2. 填写英文项目名（首字母必须是英文字母，之后可用字母、数字、下划线）和已经存在的父目录，点击“创建并打开”。启动页会在父目录下创建同名文件夹，然后进入编辑器。也可以浏览并打开已有 `.tinyproject`。
3. 新项目包含 `.tinyproject`、`assets/Startup.scene`、基础模型/材质/输入映射/Shader、`src/Game.hpp`、`src/Game.cpp`、`src/main.cpp`、`CMakeLists.txt` 和项目 README。创建前目标文件夹必须不存在；创建不会覆盖已有内容。
4. 在项目编辑器中选择“文件 → 生成 Visual Studio 解决方案”。等待结果窗口显示 `build/<项目名>.sln`。如果 CMake 没有安装、项目配置失败或引擎依赖缺失，窗口会显示 CMake 诊断；修复后可以再次点击生成。
5. 用 VS 2022 打开 `.sln`，选 `Debug` 或 `Release`，构建项目同名游戏目标。项目代码从 `src/Game.cpp` 开始：`ProjectGame::OnInitialize` 查找 `Player`，`OnUpdate` 读取 `MoveX`、`MoveZ` 并修改位置。可在这里加入交互、规则和胜负条件。新增 `.cpp` 文件会由项目 CMake 自动纳入下一次配置；VS 提示需要重新配置时接受即可。
6. 从 VS 启动同名游戏目标，或在项目根目录运行 `build/Release/<项目名>.exe <项目名>.tinyproject`。生成的 VS 启动设置已传入项目文件路径，并把工作目录设为项目根目录。

编辑器的“运行 / Play”目前只验证场景、引擎组件及编辑器内运行状态，**不会编译或加载项目 `src/Game.cpp`**。修改项目 C++ 后，要重新构建并运行项目游戏程序才能看到效果。生成的项目 README 也写明了这点。

已有项目仍可直接启动：

```powershell
.\build\Release\tinyengine_editor.exe D:\Projects\MyGame\MyGame.tinyproject
```

启动页会检查项目文件、素材目录、输入配置和启动场景。文件缺失或场景损坏时会留在启动页显示错误。
