# 碰撞加速与性能验证

## 当前结构

内置物理后端采用两层 AABB 树。场景层分别管理静态碰撞体和非静态碰撞体；三角网格层按三角形建立局部空间 BVH。球、胶囊和盒之间仍使用现有 AABB 接触近似，凸包沿用 GJK，球体扫掠仍采用扩张 AABB 的原有近似语义。

树按物体中心分布选择轴并进行中位数分割，每个叶子最多包含 4 个负载。物体成员不变时更新叶子并自底向上 refit；成员变化，或节点表面积总和超过构建时的两倍时重建。静态物体位置未变时复用已有树。

仿真仍按原 ColliderComponent 遍历顺序收集对象，再按 X 最小值排序；BVH 只替代候选查找，候选按旧排序排名执行响应。静态与静态之间的事件、触发器、层/掩码、关节排除以及 Enter/Stay/Exit 均保留。与 Chaos 的区别是这里没有新增休眠系统，也没有跳过原有静态碰撞事件。

## 网格缓存

同一个 PhysicsWorld 内，同一路径的碰撞体共享只读顶点、三角形和 BVH。缓存按 PlatformFile 的读取上下文及来源元数据失效，覆盖：

- 普通文件和挂载目录内文件的大小或修改时间变化。
- Pak 的大小或修改时间变化，以及挂载、卸载、优先级和读取策略变化。
- 相对路径对应的工作目录变化。
- 首次加载失败后，来源文件出现或被修改。

每次公开操作内，同一路径只进行一次元数据检查。缓存不会重复读取未变化的网格内容。旧路径的缓存会保留至 `PhysicsWorld::clear()` 或实例销毁；`clear()` 同时清空空间树、事件和统计。若外部工具强制保留文件大小和修改时间，应调用 `clear()` 强制重新读取。

查询会更新内部缓存，同一个 PhysicsWorld 不支持并发查询或同时仿真。复制 PhysicsWorld 后，缓存状态在第一次修改时分离，只读网格数据继续共享。

## 正确性边界

包围盒直接按仿射矩阵各项符号选择极值角点，保持与顶点变换相同的运算顺序，避免中心/半径重建导致的向内舍入。旋转、非均匀缩放、反射和零缩放无需求逆矩阵。

射线 slab 检查只把精确为零的方向分量视作平行，避免长距离射线的小分量在树剪枝时被误判。三角形边缘射线、近似平行射线、旋转网格接触均有回归覆盖。

由于 ECS 允许通过组件指针直接修改位置、形状和刚体类型，每次场景查询仍需要 O(n) 扫描以同步当前包围盒。树加速的是候选筛选和三角形访问；不能把整个查询宣称为 O(log n)。真正大量重叠的物体仍然会产生大量候选，一张超大三角形也不能通过树细分成多个三角形。

## 基准与复现

2026-10-25，在同一台 Windows/MSVC 开发机上使用 Debug 构建，优化前后均先执行一次同样查询/仿真进行预热。以下为合成场景单次测量，不代表所有游戏的加速比；首次网格加载和 BVH 构建不包含在射线计时区间内。

| 场景 | 优化前 | 优化后 |
|---|---:|---:|
| 4096 个分散三角形，40 次射线查询 | 12112.2 ms | 7.25 ms |
| 1024 个同 X、沿 Y 分散的盒子，5 次物理步进 | 3471.73 ms | 36.54 ms |
| 上一场景再加入 X 半长为 1000000 的静态盒子，5 次步进 | 未测量 | 38.12 ms |

最终基准中，预热加 40 次射线共加载网格 1 次、访问三角形 41 次。1024 个盒子预热加 5 步共执行 129024 次树包围盒检查，即每步 21504 次；原 X 扫描每步需要检查 523776 个物体对。加入超大盒子后，每步树包围盒检查为 21528 次。因此本轮没有增加超大物体专用列表；多个超大物体的实际场景仍应单独测量。

```powershell
cmake --build intermediate/Build/Editor --config Debug --target tinyengine_physics_acceleration_tests -j 4
ctest --test-dir intermediate/Build/Editor -C Debug -R '^tinyengine_physics_acceleration$' --output-on-failure
.\intermediate\Build\Editor\Debug\tinyengine_physics_acceleration_tests.exe --benchmark
```

`GetStatistics()` 返回自上次 `clear()` 起的累计快照：`meshLoads` 为实际加载尝试数（包含失败），`triangleTests` 为窄阶段访问的三角形次数，`triangleBoundsTests` / `sceneBoundsTests` 为树遍历执行包围盒谓词的次数，`staticTreeBuilds` / `dynamicTreeBuilds` 为非空树重建次数。统计不包含 ECS 同步遍历，也不等同于最终接触对数量。

回归使用生成的几何文件，覆盖缓存与挂载失效、工作目录切换、缺失资源恢复、最近命中、旋转/缩放、球体接触响应、组件直接修改、刚体分类变化、实体删除与代际复用、跨场景复用、旧响应顺序、触发器/掩码/关节过滤，以及与穷举 AABB 参考结果对比。性能通过确定性的工作量阈值验收，耗时只报告。
