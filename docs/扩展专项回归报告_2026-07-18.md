## 结论

扩展自动化共执行 68 项：53 项通过、0 项非预期失败、9 项已知失败（XFAIL）、6 项受外部环境限制。另完成 3 条编辑器黑盒鼠标流程：Gizmo 拖动、材质节点图打开、Shader 错误显示并恢复，均通过。

XFAIL 表示测试稳定复现了已经编号的产品缺陷，因此测试程序本身仍返回成功；如果缺陷修复后测试未同步，结果会变为 XPASS 并提示维护基线。BLOCKED 不计为通过，必须在对应硬件或实验环境补测。

## 外部环境阻塞

- 仓库没有可分发的有效 OGG 长音频样本，未完成真实 OGG 长流解码；坏文件拒绝和 PCM 流式 Mixer 已通过。
- 当前只有 Windows，Linux/macOS 与非 Windows FreeType 打包未测。
- 没有物理手柄，震动未测；SDL 虚拟手柄热插拔已通过。
- 只有当前一张 GPU，NVIDIA/AMD/Intel 跨厂商图像对比未测。
- 没有干净 Windows VM，缺少 VC Runtime 的发布包启动未测。
- 没有外部主机和网络损伤实验室，NAT 与恶意公网客户端未测；本机真实 UDP 和协议边界已通过。

## 测试钩子约束

音频 Mixer 需要确定性读取内部 Voice 和输出采样。本轮只增加了 `TINYENGINE_TEST_HOOKS` 宏保护的 `TestGetVoiceCount()` 与 `TestMixFrames()`，声明和实现旁均有 `TEST HOOK` 注释。该宏只在 `TINYENGINE_BUILD_TESTS=ON` 时由 CMake 定义；测试关闭的发布构建不会暴露这些接口。

鼠标测试使用 Win32 发送物理像素鼠标/键盘事件，并在独立工程中运行。Gizmo 测试在退出前恢复原始场景文件；Shader/材质测试只写入 `Saved/EditorAdvancedQA/`。
