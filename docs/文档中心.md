## 文档维护约定

- README 只保留产品定位、能力总览和最短上手路径；详细说明写入 `docs/`。
- 当前功能按使用场景统一维护在 `功能总览.md`；版本记录只说明功能在哪个版本进入主链路。
- 功能实现变化必须同步项目架构、相关专题和后续工作，不能只修改实现日志。
- 同一主题只维护一个当前事实来源；旧报告只保留可追溯的历史基线，并明确标注日期。
- 新增持久化格式时，必须在 `资产与数据格式.md` 记录 Magic、当前版本、兼容范围和安全上限。
- 新增命令行入口时，必须在 `工具参考.md` 记录完整参数、产物和非零退出语义。
- “已完成”表示代码路径可编译、可测试、可运行；质量或规模边界必须与完成项同时记录。
- 本地绝对路径只出现在构建示例中，资产和项目文件内部始终使用项目相对路径。
