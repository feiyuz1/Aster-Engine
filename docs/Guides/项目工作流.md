# 新建项目与编写游戏代码

开发机需要 Windows、Visual Studio 2022 的 C++ 桌面开发和 CMake。使用 SDK 包时直接打开根目录的 `Aster-Engine.cmd`；引擎开发者的构建入口见[构建指南](构建指南.md)。

1. 启动编辑器，填写项目名称和父目录，点击“创建并打开”。
2. 编辑器创建项目、生成 VS 工程并首次编译 DLL；成功后自动打开项目。失败时保留文件并显示诊断，可以修复后重试。
3. 点击运行，默认场景中的 Player 会旋转；点击停止恢复编辑场景。
4. 游戏代码在 `Source/Game.cpp`。打开 `build/<项目名>.sln`，在 VS 中编译、设置断点和启动调试；调试宿主和项目参数已经配置。
5. 需要重新生成工程时，先双击 SDK 的 `Programs/ProjectTool/TinyEngineProjectTool.exe` 注册菜单，之后右键 `.tinyproject` 选择“生成 Visual Studio 工程”。Windows 11 使用“显示更多选项”。生成操作不会编译或运行项目代码。
6. 修改 C++ 后，当前流程是保存场景、关闭编辑器、在 VS 中重新生成 DLL，再打开编辑器运行。运行中热重载尚未实现。

项目代码只依赖安装的 SDK，项目目录与引擎源码分离。详细编译、生命周期与调试步骤见[项目代码开发](项目代码开发.md)。当前 SDK 提供项目会话级入口；自定义组件的 Inspector、持久化、撤销和 Prefab 接入，以及完整项目代码打包流程属于后续阶段。

已有项目可以通过启动页浏览打开，或把 `.tinyproject` 作为编辑器启动参数。启动页会检查项目配置、基础素材和场景；缺失时显示错误。
